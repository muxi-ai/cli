# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities through the main MUXI repository:

**[Report a vulnerability](https://github.com/muxi-ai/muxi/security/advisories/new)**

For details on our security policy, supported versions, and disclosure process, see:

**[MUXI Security Policy](https://github.com/muxi-ai/muxi/blob/main/SECURITY.md)**

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest  | ✅        |
| < Latest | ❌       |

Only the latest release receives security updates. Please upgrade to the latest version.
